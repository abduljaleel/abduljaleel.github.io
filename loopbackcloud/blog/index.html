2026-03-01 Getting started

One command, three clouds

Loopback Cloud boots AWS (localhost:4566), Azure (localhost:4577), and GCP (localhost:4588) from a single docker compose up. Same SDKs, CLIs, and IaC you use in production — no account, no auth token, no spend. Point your tools at loopback endpoints and they behave like the real thing.

A built-in Model Context Protocol server lets AI agents inspect, provision, and stress real infra — 42 AWS / 24 Azure / 19 GCP tools covering every lab. Agents create S3 buckets, attach interconnects, fast-forward clocks, and invoke the offline GenAI gateway without ever leaving the sandbox.

2026-02-05 Interconnect

Multicloud interconnect: cross-cloud calls, gated by default

Model AWS-style interconnect attachments between clouds. Cross-cloud API calls return 403 until you authorize a link via /_loopback/interconnects/authorize — then S3 in AWS can talk to Blob Storage in Azure, or Pub/Sub in GCP. Test failover, retries, and network partitions without wiring real VPC peering.
